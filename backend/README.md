# backend · paquete `atlas`

Adaptadores por formato → IR → AGF 1.0 → inferencia, calidad, relaciones, embeddings, memoria. CLI `atlas`.
Instalación: `pip install -e backend` (o `pip install -r requirements-dev.txt` desde la raíz). Pruebas: `pytest -q backend/tests`.
Detalle de comandos y proveedores de modelos: `docs/GUIA-USO.md` y `docs/MODELOS-ABIERTOS.md`.
